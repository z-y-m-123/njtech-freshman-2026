> 第一次走进南工，从这里开始。

## 从这里出发

南工起点站是一份面向南京工业大学新生的校园导航。它不想把信息堆成一张长清单，而是按真正会遇到的场景整理入口：出发前知道该准备什么，到校后知道去哪里找答案，开始上课后还能继续查服务、探索校园。

## 你会在这里找到

| 模块 | 可以做什么 |
| --- | --- |
| 报到准备 | 查看行前清单、到校路线与报到相关提醒。 |
| 校园地图 | 快速定位校园区域和常用地点。 |
| 宿舍生活 | 了解住宿信息、宿舍介绍与图集。 |
| 办事服务 | 找到课表、网络等日常事务入口。 |
| 官方入口 | 重要事项直接跳转至学校官方系统。 |
| 新生留言 | 留下问题、经验与轻量互助信息。 |
| 成长导航 | 浏览社团、竞赛、升学与相关校园信息。 |

## 在需要的时候打开

**还没出发**：先看要带什么、怎么到校、抵达之后优先做什么。

**刚到校园**：从宿舍、地图和常用服务入口开始熟悉环境。

**开始上课**：通过官方入口继续查询课表、网络和校内事务。

**想多了解一点**：再去看看社团、竞赛、转专业、升学和校园生活信息。

## 信息使用原则

- **官方优先**：涉及选课、学籍、缴费和其他重要事务时，始终以学校官方系统和通知为准。
- **按需整理**：优先保留新生真正会用到的信息与入口，减少不必要的跳转。
- **轻量访问**：手机打开也能快速找到目的地，不要求安装额外应用。
- **持续更新**：内容会结合实际使用反馈逐步完善；具体时间、政策和名额请以学校最新通知为准。
